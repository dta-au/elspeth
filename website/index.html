Before you begin

A tool to evaluate carefully.

ELSPETH is a pre-release prototype with limited user testing. It is not ready for general production use.

Start with synthetic or public data. People remain responsible for the workflow, the evidence they retain and any decision informed by an output.

Current version: 0.8.10 · Unreleased · Read the changelog

0.7.0 introduced the LLM-primary, staged Composer. 0.7.1 added recoverable publication and shared proposal validation. 0.8.0 added unified lineage and scope-bound collection, document and multimodal transforms, stronger Composer contracts and review surfaces, and production hardening. 0.8.1 extended PostgreSQL replica operation with durable run admission, Composer progress, single-use tickets and shared budgets. 0.8.2 adds bounded Composer validation, resource limits for reference joins, and stricter release-check evidence. 0.8.3 added EFS archive recovery and preparation for authenticated HTTPS Composer progress. 0.8.4 added restricted SQL analysis, credential revocation and bounded evidence handling.

Pre-1.0 APIs and schemas may change without backward-compatibility guarantees. Unsupported existing session, Landscape and local-auth stores must be preserved and refused before incompatible writes. Do not recreate, delete, restamp or migrate them for this candidate. This is a pre-1.0 release. Implemented controls support defensible workflows, not whole-platform certification.
