The ELSPETH brand mark as live text — JetBrains Mono 700, uppercase, 0.18em tracking. There is no graphical logo; use this everywhere the brand appears (header, login).

```jsx
<WordMark />
<WordMark size={28} as="h1" />
```

`size` (px number or CSS length) and `as` (element). Inherits/overridable colour via style; defaults to `--color-text`.
