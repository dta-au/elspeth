## Reviewed contracts

- Provider failures are classified at the physical call boundary; guided authentication/bad-request outcomes retain corrective durable reasons and suppress blind Retry. Auto-title settles dispatched failures before preserving best-effort transport handling or propagating first-party faults.
- Guided Chat, PLAN, START, RESPOND, reenter, CONVERT and reviewed back-edit changes retain submitted terminal writers through repeated caller cancellation. The reviewed tests distinguish successful durable completion, audit-aware failure, fence loss, child self-cancellation and required integrity failure. Generic RESPOND/reenter do not manufacture a progress stream.
- Ordinary rejection replay validates terminal event identity, payload and actor. Canonical decisions retain strict existing authority. Pipeline preparation timeout is sanitized 504; committed proposals keep their dependent interpretation-review surfacing obligation under joined custody, including replay.
- Freeform ingress binds the client request UUID and original nullable state to one canonical route-owned user message before sequence allocation. Exact accepted retries reconcile without provider redispatch; deliberate recompose requires the expected user message identity. Epoch 69, immutable receipt triggers and same-session foreign keys agree with that contract; forked transcripts do not copy acceptance keys.
- Send and recompose establish continuation ownership immediately after inline provider return, within the disconnect-watcher scope. They join state/assistant/audit/response/progress obligations while retaining lease and lock, propagate observed child failures once, and preserve completed durable metrics through lost HTTP delivery. The separate SQL writes are not an atomic turn transaction.
- The executed-run quota callbacks use synchronous shared transaction cores, retain committed admission/settlement receipt ownership, stop SDK entry on uncertain admission, and classify uncertain commit receipts as integrity failures without fabricating usage. Tests include exact real Landscape settlement and replay/conflict evidence.
- Frontend compose/read generations prevent older requests from reclaiming publication. Execution terminal outcomes resist stale list, cancel and stream updates, while authoritative accounting can enrich terminal rows. Conflicting terminal evidence receives bounded reconciliation with a fetch deadline. Code-4503 reconnect backoff survives socket open until healthy-stream evidence; obsolete socket callbacks are fenced.
