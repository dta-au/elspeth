**Design decisions this re-base makes (each carried by a test named in the step that lands it):**

- **D-a. `state_id` is always sent, as a string or `null`.**
  - This is today's wire: `stores/sessionStore.ts:1499-1501` passes `?? null`, and `api/client.ts:963-965`
    includes the key whenever it is defined.
  - The contract measured that an absent `state_id` and an explicit `null` hash identically, and both mean "no state"
    (`contract.md:194`, ruling 7).
  - The recompose body gains `state_id` too: `{operation_id, expected_user_message_id, state_id}` (contract §Wire DTOs,
    ruling 5).
  - Pinned in Step 7 (custody body shape) and Step 2 (client body).
- **D-b. The boot latch becomes the state-loaded gate.**
  - E16 deletes `composeTimeoutReady`. Its only job was to gate Send until a client abort ceiling existed, and the
    client no longer aborts a turn.
  - Ruling 5 needs a gate that holds Send until `compositionStateLoaded` (Review Focus 8). So every surface that read
    `composeTimeoutReady` (`ChatInput`, `SideRailValidationBanner`, `ChatPanel` decision Apply,
    `TutorialFreeformShell`) now reads `compositionStateLoaded`.
  - The store's `sendMessage` / `retryMessage` refuse while it is false, which is the invariant for programmatic
    callers.
  - `composerTimeoutUnavailable`, its setter, `COMPOSE_CONNECTING_MESSAGE`, `COMPOSE_UNAVAILABLE_MESSAGE` and the two
    "unavailable" CSS rules exist only to explain the deleted latch, so they go too.
  - The gate's visible reason is the new constant `COMPOSE_LOADING_SESSION_MESSAGE = "Loading this session…"`. The
    wording is a copy decision, recorded in Review note 2.
- **D-c. Every Retry of a failed row is a NEW user action.**
  - A terminal row answers a replay of its own id with its stored terminal (contract §HTTP: "a same id + body → 202
    with the current status"). Re-sending a failed id would therefore show the same failure forever.
  - Retry always mints a new operation id and reads the head at the click (contract §Frontend ruling-5 bullets;
    Review Focus 7).
  - Only acknowledgement recovery (a transport-ambiguous submit, handled inside the poll loop) re-sends the SAME id and
    body.
  - `ChatMessage.local_requested_state_id` loses its only reader (the old local-row replay) and is deleted.
- **D-d. After every non-success terminal, the store reloads the authoritative state** (contract §Frontend).
  - The reload replaces the old abort-only resync.
  - It keeps its banner refinement for Stop and deadline.
  - It moves `recoveryStartedCompositionVersion` onto the reloaded head when that head IS the recovery draft. Without
    that, a plugin-crash recovery draft that the server saved as the new head would ask the user to confirm an Apply of
    the state they are already looking at.
- **D-e. `createSession` now detaches the attached operation and sets `isComposing: false`.**
  - This is the latent leak in frontend.md §2, "Unchanged".
  - Under async it becomes a stuck Send: a new session opened while a turn runs keeps `isComposing` true, and nothing
    ever clears it.
  - `isComposing` is the ruling-5 guard signal, so this cut owns it (Review note 7).

**Interfaces:**

Consumes (HTTP, from N13 and N14; contract §HTTP and §Wire DTOs):

- **Send.** `POST /api/sessions/{sid}/messages` with body `{operation_id, content, state_id}`. `operation_id` is a
  canonical v4 UUID of 36 characters. `state_id` is a canonical UUID or `null`. The strict DTO's `mode="before"`
  parsers accept the string form (`critique.md` gap 2).
- **Recompose.** `POST /api/sessions/{sid}/recompose` with body `{operation_id, expected_user_message_id, state_id}`.
- **Acknowledgement.** Both answer `202 {operation_id, kind, status, poll_after_ms}`. A replay of the same id and body
  answers 202 with the current status.
- **Refusals:**
  - 409 `{"detail":{"error_type":"composer_operation_active","detail":…,"operation_id":…,"kind":…}}`;
  - 409 `{"detail":{"error_type":"composer_operation_conflict","detail":…}}`;
  - 429 `{"detail":{"error_type":"composer_queue_full","detail":…,"retry_after":n}}`;
  - 404 `{"detail":"Session not found"}` (ownership);
  - 401 and 422 are unchanged.
- **Poll.** `GET /api/sessions/{sid}/operations/{oid}` returns 200 with 9 keys:
  `{operation_id, kind, status, cancel_requested, poll_after_ms, deadline_at, deadline_remaining_ms, result, error}`.
  - `deadline_remaining_ms` is an integer ≥ 0 computed on the database clock, and 0 on a terminal row (N13 Produces).
  - `result` and `error` are `null` when absent.
  - A 404 body is `{"detail":"Operation not found"}` or `{"detail":"Session not found"}`. Every answer carries
    `Cache-Control: no-store` (N13 Produces).
- **Cancel.** `POST /api/sessions/{sid}/operations/{oid}/cancel` answers 200 when the row is terminal (a completed job
  wins), or 202 with `cancel_requested: true`. The body has the same 9 keys, and the 404s are the same two.
- **Error.** `ComposerOperationError {http_status, failure_code, error_type, body, diagnostic_id}`.
  - `failure_code` is one of `http_error`, `operation_failed`, `worker_lost`, `request_cancelled`, `deadline_expired`.
  - `body` is the exact JSON the synchronous route or handler would have sent (E4). The ruling-5 refusal is the flat
    409 `{"error_type":"stale_compose_state","detail":"The session changed before this request started. Review the current pipeline and send again.","request_id":…}`
    (E6).
  - E22 fixes three bodies:
    - 504 `composer_operation_deadline_expired`;
    - 503 `composer_operation_worker_lost`;
    - 499 `request_cancelled`, with a nested `detail` dict.
- **Transcript.** `GET /api/sessions/{sid}/messages` rows carry `operation_id: str | None` (N14, ruling 6). A
  send-created user row carries its job's id.
- **Progress.** The composer progress `request_id` is the persisted user-message id (E20), so the pollers are
  unchanged.
- **System status.** `GET /api/system/status` keeps `composer_timeout_seconds`, which is now informational (E16).
  There is no new key (E15).

const CANONICAL_UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/;

  "assistant",

  "tool",
  "audit",

function invalid(path: string, detail: string): never {
  throw new ComposerOperationDecodeError(path, detail);
}

function record(value: unknown, path: string): Record<string, unknown> {
  if (typeof value !== "object" || value === null || Array.isArray(value)) {
    invalid(path, "expected object");
  }
  return value as Record<string, unknown>;
}

function exactRecord(
  value: unknown,
  path: string,
  required: readonly string[],
): Record<string, unknown> {
  const result = record(value, path);
  const allowed = new Set(required);
  for (const key of required) {
    if (!Object.prototype.hasOwnProperty.call(result, key)) invalid(path, `missing ${key}`);
  }
  for (const key of Object.keys(result)) {
    if (!allowed.has(key)) invalid(path, `unexpected ${key}`);
  }
  return result;
}

function stringValue(value: unknown, path: string): string {
  if (typeof value !== "string") invalid(path, "expected string");
  return value;
}

function nullableString(value: unknown, path: string): string | null {
  return value === null ? null : stringValue(value, path);
}

function booleanValue(value: unknown, path: string): boolean {
  if (typeof value !== "boolean") invalid(path, "expected boolean");
  return value;
}

function nonNegativeInteger(value: unknown, path: string): number {
  if (typeof value !== "number" || !Number.isSafeInteger(value) || value < 0) {
    invalid(path, "expected non-negative integer");
  }
  return value;
}

function canonicalUuid(value: unknown, path: string): string {
  const decoded = stringValue(value, path);
  if (!CANONICAL_UUID.test(decoded)) invalid(path, "expected canonical UUID");
  return decoded;
}

function timestamp(value: unknown, path: string): string {
  const decoded = stringValue(value, path);
  if (!Number.isFinite(Date.parse(decoded))) invalid(path, "expected ISO-8601 timestamp");
  return decoded;
}

  }

    "failure_code",
    "error_type",
    "body",

  };
}

/**
 * Decode a stored terminal operation envelope's public body (the `error.body`
 * of a failed composer operation, delivered inside a 200 poll) into the SAME
 * ApiError parseResponse would have thrown for the synchronous response
 * (spec §5; contract §Frontend). No 401 logout (an envelope is not a
 * credential rejection), no response header, and a body without detail
 * yields detail "" — what parseResponse yields over HTTP/2, where statusText
 * is empty.
 */
export function apiErrorFromBody(status: number, body: unknown): ApiError {
  return buildApiError(status, body, "", undefined);
}

export async function parseResponse<T>(
  response: Response,
  options: ParseResponseOptions = {},
): Promise<T> {
  if (!response.ok) {
    // A rejected credential can only invalidate the login that sent it.
    // Dynamic import avoids circular dependency at module load time
    // (authStore imports from client, client imports authStore for logout).
    if (response.status === 401 && options.logoutOnUnauthorized !== false) {
      const { useAuthStore } = await import("@/stores/authStore");
      if (responseOwnsCredential(response, useAuthStore.getState().token)) {
        await useAuthStore.getState().logout();
      }
    }

    // Parse the error envelope into one ApiError contract. Canonical backend
    // fields are `error_type`, `detail`, and optional `errors`; `kind` and
    // `message` remain accepted as compatibility aliases for older execution
    // responses.
    let body: unknown;
    try {
      body = await response.json();
    } catch {
      // Response body wasn't JSON -- use statusText as detail fallback
      body = undefined;
    }
    throw buildApiError(
      response.status,
      body,
      response.statusText,
      optionalResponseHeader(response, "X-ELSPETH-Plugin-Snapshot"),
    );
  }

  return response.json() as Promise<T>;
}

/**

 * the 202 acknowledgement once the server committed the queued row (or, for
 * a replay of the same id and body, the row's current status). The ownership
 * 404 resolves `{kind: "session_missing"}` so nothing is resubmitted into a

 * (contract E2); every other refusal throws parseResponse's ApiError. A
 * malformed 202 body throws ComposerOperationDecodeError: the server DID
 * accept, so the caller treats it as ambiguous and polls by id.
 */
export async function submitComposerOperation(
  sessionId: string,
  kind: ComposerOperationKind,
  body: ComposerOperationRequestBody,
  signal?: AbortSignal,
): Promise<ComposerOperationAccepted | ComposerOperationSessionMissing> {
  const response = await authFetch(
    `/api/sessions/${sessionId}/${COMPOSER_OPERATION_ROUTE[kind]}`,
    {
      method: "POST",
      headers: authHeaders("application/json"),
      body: JSON.stringify(body),
      signal: composerOperationSignal(signal),
    },
  );

    const refusalBody = await jsonBodyOrUndefined(response);
    if (response.status === 404) {
      const missing = decodeComposerOperationNotFoundBody(refusalBody);
      if (missing !== null && missing.kind === "session_missing") return missing;

      const active = decodeComposerOperationActiveBody(refusalBody);
      if (active !== null) {
        const activeRefusal: ComposerOperationActiveRefusal = {
          ...buildApiError(409, refusalBody, response.statusText, undefined),
          active_operation: active,
        };
        throw activeRefusal;
      }
    }
    throw buildApiError(
      response.status,
      refusalBody,
      response.statusText,
      optionalResponseHeader(response, "X-ELSPETH-Plugin-Snapshot"),
    );
  }
  return decodeComposerOperationAccepted(await parseResponse<unknown>(response));

 * §HTTP; Review Focus 2): "Operation not found" (a missing row in an owned
 * session; an initial one is not proof an in-flight POST cannot still commit,
 * spec §2, so the caller decides) versus "Session not found" (the session is
 * gone, archived or not this user's; nothing may be resubmitted into it). Any
 * other 404 body throws parseResponse's ApiError.
 */
async function composerOperationLookup(
  response: Response,
): Promise<ComposerOperationStatus | ComposerOperationNotFound> {
  if (response.status === 404) {
    const body = await jsonBodyOrUndefined(response);
    const missing = decodeComposerOperationNotFoundBody(body);

    throw buildApiError(
      404,
      body,
      response.statusText,
      optionalResponseHeader(response, "X-ELSPETH-Plugin-Snapshot"),
    );
  }
  return decodeComposerOperationStatus(await parseResponse<unknown>(response));
}

/**
 * Per-tab custody of freeform composer operations (spec 2026-09-16 §2,
 * contract §Frontend).
 *
 * The SPA mints the operation id BEFORE the POST and keeps the id AND the
 * exact strict request body until it observes a terminal row. An ambiguous
 * transport failure or a same-tab reload can then poll by id and, only when
 * no row exists, resubmit the identical id and body. This DELIBERATELY
 * reverses sessionOperationRetry's fingerprint-only invariant
 * (sessionOperationRetry.ts:34-43, :181-198) for this one kind: a
 * fingerprint cannot be resubmitted, and reload-resume is the point. The
 * reversed invariant still holds for state_revert and session_fork, which
 * keep using sessionOperationRetry unchanged.
 *
 * The body is what the user typed in this tab. It lives in sessionStorage
 * (per tab, gone with the tab) and is removed at the first observed terminal
 * row, on logout (sessionStore.reset) and after 24 h. There is NO orphan
 * sweep on selectSession: a descriptor that survives a reload is exactly
 * what resumeComposerOperation must find. Another tab never sees this
 * storage; it learns about a running operation from the server's 409
 * composer_operation_active (contract E2).
 */
import type {
  ComposerOperationKind,
  ComposerOperationRequestBody,
} from "@/types/composerOperations";

export const COMPOSER_OPERATION_CUSTODY_STORAGE_KEY = "elspeth_composer_operations_v1";
const STORAGE_SCHEMA = "composer-operations.v1";
const MAX_DESCRIPTOR_AGE_MS = 24 * 60 * 60 * 1000;
export const MAX_COMPOSER_OPERATION_CUSTODY_BYTES = 256 * 1024;
// crypto.randomUUID() output (version 4, RFC variant).
const OPERATION_UUID_PATTERN = /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/;
// sessions.id is String(128) (src/elspeth/web/sessions/models.py).
const MAX_SESSION_ID_LENGTH = 128;

export interface ComposerOperationDescriptor {
  sessionId: string;
  operationId: string;
  kind: ComposerOperationKind;
  body: ComposerOperationRequestBody;
  createdAt: number;
}

export type ComposerOperationCustodyRequest =
  | {
      sessionId: string;
      kind: "compose_message";
      content: string;
      stateId: string | null;
    }
  | {
      sessionId: string;
      kind: "compose_recompose";
      expectedUserMessageId: string;
      stateId: string | null;
    };

// The page's authority once loaded (null = not read from storage yet). A
// refused or partial storage write never loses custody for THIS page.
let memory: ComposerOperationDescriptor[] | null = null;

function storageOrNull(): Storage | null {
  try {
    return typeof window === "undefined" ? null : window.sessionStorage;
  } catch {
    return null;
  }
}

function isSessionId(value: unknown): value is string {
  return typeof value === "string" && value.length > 0 && value.length <= MAX_SESSION_ID_LENGTH;
}

function isNullableId(value: unknown): boolean {
  return value === null || (typeof value === "string" && value.length > 0);
}

function hasExactKeys(body: Record<string, unknown>, keys: readonly string[]): boolean {
  const actual = Object.keys(body);
  return actual.length === keys.length && keys.every((key) => Object.prototype.hasOwnProperty.call(body, key));
}

function isBody(kind: ComposerOperationKind, value: unknown, operationId: string): boolean {
  if (typeof value !== "object" || value === null || Array.isArray(value)) return false;
  const body = value as Record<string, unknown>;
  if (body.operation_id !== operationId || !isNullableId(body.state_id)) return false;
  if (kind === "compose_message") {
    return hasExactKeys(body, ["operation_id", "content", "state_id"]) && typeof body.content === "string";
  }
  return (
    hasExactKeys(body, ["operation_id", "expected_user_message_id", "state_id"]) &&
    typeof body.expected_user_message_id === "string" &&
    body.expected_user_message_id.length > 0
  );
}

function isDescriptor(value: unknown): value is ComposerOperationDescriptor {
  if (typeof value !== "object" || value === null || Array.isArray(value)) return false;
  const record = value as Record<string, unknown>;
  return (
    (record.kind === "compose_message" || record.kind === "compose_recompose") &&
    isSessionId(record.sessionId) &&
    typeof record.operationId === "string" &&
    OPERATION_UUID_PATTERN.test(record.operationId) &&
    typeof record.createdAt === "number" &&
    Number.isFinite(record.createdAt) &&
    record.createdAt >= 0 &&
    isBody(record.kind, record.body, record.operationId)
  );
}

function live(
  descriptors: readonly ComposerOperationDescriptor[],
  now = Date.now(),
): ComposerOperationDescriptor[] {
  return descriptors.filter(
    (descriptor) =>
      descriptor.createdAt <= now && now - descriptor.createdAt <= MAX_DESCRIPTOR_AGE_MS,
  );
}

function encoded(descriptors: readonly ComposerOperationDescriptor[]): string {
  return JSON.stringify({ schema: STORAGE_SCHEMA, descriptors });
}

function byteLength(value: string): number {
  return new TextEncoder().encode(value).byteLength;
}

function load(): ComposerOperationDescriptor[] {
  if (memory !== null) {
    memory = live(memory);
    return memory;
  }
  const storage = storageOrNull();
  let raw: string | null = null;
  if (storage !== null) {
    try {
      raw = storage.getItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      raw = null;
    }
  }
  if (raw === null) {
    memory = [];
    return memory;
  }
  try {
    if (byteLength(raw) > MAX_COMPOSER_OPERATION_CUSTODY_BYTES) {
      throw new Error("oversized composer operation custody envelope");
    }
    const parsed = JSON.parse(raw) as unknown;
    if (typeof parsed !== "object" || parsed === null) {
      throw new Error("invalid composer operation custody envelope");
    }
    const envelope = parsed as Record<string, unknown>;
    if (envelope.schema !== STORAGE_SCHEMA || !Array.isArray(envelope.descriptors)) {
      throw new Error("invalid composer operation custody envelope");
    }
    if (!envelope.descriptors.every(isDescriptor)) {
      throw new Error("invalid composer operation custody descriptor");
    }
    memory = live(envelope.descriptors);
  } catch {
    memory = [];
    try {
      storage?.removeItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      // Memory is authoritative for this page either way.
    }
  }
  return memory;
}

function persist(descriptors: ComposerOperationDescriptor[]): void {
  memory = descriptors;
  const storage = storageOrNull();
  if (storage === null) return;
  // The newest descriptors win the byte budget: evict the oldest from STORAGE
  // until the envelope fits. An evicted descriptor stays in this page's
  // memory; only a reload loses it, and the server's 409
  // composer_operation_active is the backstop for that (contract E2).
  const stored = [...descriptors].sort((left, right) => left.createdAt - right.createdAt);
  while (stored.length > 0 && byteLength(encoded(stored)) > MAX_COMPOSER_OPERATION_CUSTODY_BYTES) {
    stored.shift();
  }
  if (stored.length === 0) {
    try {
      storage.removeItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      // Memory stays authoritative for this page.
    }
    return;
  }
  try {
    storage.setItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY, encoded(stored));
  } catch {
    // Quota refusal or disabled storage: memory stays authoritative for this
    // page; a reload then cannot resume (the 409 backstop above applies).
  }
}

/** Mint the operation id, freeze the exact body, persist both. Replaces any
 *  descriptor the session already had: one per session (contract §Frontend). */
export function acquireComposerOperationCustody(
  request: ComposerOperationCustodyRequest,
): ComposerOperationDescriptor {
  if (!isSessionId(request.sessionId)) {
    throw new Error("composer operation sessionId must be a non-empty string of at most 128 characters");
  }
  const operationId = crypto.randomUUID();
  const body: ComposerOperationRequestBody =
    request.kind === "compose_message"
      ? { operation_id: operationId, content: request.content, state_id: request.stateId }
      : {
          operation_id: operationId,
          expected_user_message_id: request.expectedUserMessageId,
          state_id: request.stateId,
        };
  const descriptor: ComposerOperationDescriptor = {
    sessionId: request.sessionId,
    operationId,
    kind: request.kind,
    body,
    createdAt: Date.now(),
  };
  persist([
    ...load().filter((existing) => existing.sessionId !== request.sessionId),
    descriptor,
  ]);
  return { ...descriptor };
}

export function findComposerOperationCustody(
  sessionId: string,
): ComposerOperationDescriptor | null {
  const descriptor = load().find((candidate) => candidate.sessionId === sessionId);
  return descriptor === undefined ? null : { ...descriptor };
}

/** Clear custody for exactly this operation; a newer descriptor for the
 *  same session (a later action) is left alone. */
export function clearComposerOperationCustody(sessionId: string, operationId: string): void {
  const descriptors = load();
  const kept = descriptors.filter(
    (descriptor) =>
      !(descriptor.sessionId === sessionId && descriptor.operationId === operationId),
  );
  if (kept.length !== descriptors.length) {
    persist(kept);
  }
}

export function clearAllComposerOperationCustody(): void {
  persist([]);
}

function envelopeForRejection(reason: unknown): ComposerOperationError {

    error_type: "operation_failed",

    case "failed":
      return { ...base, deadline_remaining_ms: 0, status: "failed", result: null, error: turn.outcome.error };

}

    deadline_remaining_ms: 0,
    result: null,
    error,
  };
}

function envelope(
  httpStatus: number,
  failureCode: ComposerOperationError["failure_code"],
  body: Record<string, unknown>,
  errorType: string | null,
): ComposerOperationError {
  return { http_status: httpStatus, failure_code: failureCode, error_type: errorType, body, diagnostic_id: null };
}

function deferred<T>(): { promise: Promise<T>; resolve: (value: T) => void } {
  let resolve: (value: T) => void = () => undefined;
  const promise = new Promise<T>((resolvePromise) => {
    resolve = resolvePromise;
  });
  return { promise, resolve };
}
