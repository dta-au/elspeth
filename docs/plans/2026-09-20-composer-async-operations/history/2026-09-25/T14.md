CONTRACT DEVIATION: §Frontend puts the client deadline ("explicit cancel and reconcile") under the
`hooks/useComposer.ts` bullet. The adopted-deviations row "client deadline" moves it to the store poll loop, and
review-pass decision F-B3 (contract "Review-pass decisions") fixes its mechanism.
- Measured reason for the location: the deadline facts exist only on the poll/cancel body
  (`ComposerOperationStatusResponse`, contract §Wire DTOs); the 202 body (`ComposerOperationAcceptedResponse`) has
  none. The hook never sees a poll body, and a hook-owned timer dies on reload and on an A→B→A switch, which are
  exactly the cases where the store's `resumeComposerOperation` reattaches. A hook timer would leave a resumed
  operation with no client deadline.
- Mechanism (F-B3, Review Focus #1): the client NEVER compares the server's absolute `deadline_at` to `Date.now()`.
  A browser clock minutes off would cancel a healthy turn on its first poll (fast clock) or never cancel (slow clock).
  Every non-terminal poll or cancel body carries `deadline_remaining_ms`, which the server computes on the DATABASE
  clock (`max(0, deadline_at − db_now)`, Tasks 2 and 12). The store arms
  `armed = performance.now() + deadline_remaining_ms + COMPOSE_CLIENT_GRACE_MS` on each such body and keeps
  `localDeadline = localDeadline === null ? armed : Math.min(localDeadline, armed)`. The re-arm only tightens: once
  the server deadline passes, `deadline_remaining_ms` is clamped at 0, so a plain overwrite would push the local
  deadline out by one poll interval per poll and never fire. Each arm is at or after the true deadline plus grace as
  this tab's monotonic clock measures it, because the server computed the remaining time before the body arrived. So
  the minimum is never early and still fires. The predicate `performance.now() >= localDeadline` is checked once per
  loop iteration before the sleep, so a poll outage still fires the last arm. It calls `cancelComposerOperation`
  once and keeps polling to the terminal row. `deadline_at` is still decoded (it is on the wire) but is never used
  for timing.
- The hook keeps the Stop wiring (`cancelActiveComposerOperation`) and stops calling `runComposeWithTimeout`, as the
  contract says. No contract name changes.
- F-B3's table text reads "arms `localDeadline = …` on every non-terminal body". Taken literally, that is a plain
  overwrite, and Step 15's overwrite control proves it never fires. This task implements the tighten-only reading
  above. The contract clause should read "…arms tighten-only: `localDeadline = min(localDeadline, armed)`". Tasks 2
  and 12 are unaffected.

CONTRACT DEVIATION (M4, Review Focus #2): §Frontend has `fetchComposerOperation` / `cancelComposerOperation` return
`ComposerOperationStatus | null` ("404 → null").
- Measured reason: the poll and cancel routes send two different 404 bodies (contract §HTTP;
  `_helpers.py:2801,2805` and Task 12 `_OPERATION_NOT_FOUND`), and `null` erases the difference. A session archived

```ts
const CANONICAL_UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/;
const MESSAGE_ROLES: ReadonlySet<string> = new Set([

  "assistant",
  "system",
  "tool",
  "audit",
]);

function invalid(path: string, detail: string): never {
  throw new ComposerOperationDecodeError(path, detail);
}

function record(value: unknown, path: string): Record<string, unknown> {
  if (typeof value !== "object" || value === null || Array.isArray(value)) {
    invalid(path, "expected object");
  }
  return value as Record<string, unknown>;
}

function exactRecord(
  value: unknown,
  path: string,
  required: readonly string[],
  optional: readonly string[] = [],
): Record<string, unknown> {
  const result = record(value, path);
  const allowed = new Set([...required, ...optional]);
  for (const key of required) {
    if (!Object.prototype.hasOwnProperty.call(result, key)) invalid(path, `missing ${key}`);
  }
  for (const key of Object.keys(result)) {
    if (!allowed.has(key)) invalid(path, `unexpected ${key}`);
  }
  return result;
}

function stringValue(value: unknown, path: string): string {
  if (typeof value !== "string") invalid(path, "expected string");
  return value;
}

function nullableString(value: unknown, path: string): string | null {
  return value === null ? null : stringValue(value, path);
}

function booleanValue(value: unknown, path: string): boolean {
  if (typeof value !== "boolean") invalid(path, "expected boolean");
  return value;
}

function nonNegativeInteger(value: unknown, path: string): number {
  if (typeof value !== "number" || !Number.isSafeInteger(value) || value < 0) {
    invalid(path, "expected non-negative integer");
  }
  return value;
}

function canonicalUuid(value: unknown, path: string): string {
  const decoded = stringValue(value, path);
  if (!CANONICAL_UUID.test(decoded)) invalid(path, "expected canonical UUID");
  return decoded;
}

function timestamp(value: unknown, path: string): string {
  const decoded = stringValue(value, path);
  if (!Number.isFinite(Date.parse(decoded))) invalid(path, "expected ISO-8601 timestamp");
  return decoded;
}

function decodeKind(value: unknown, path: string): ComposerOperationKind {

function decodeMessage(value: unknown, path: string): ChatMessage {
  const message = record(value, path);
  stringValue(message.id, `${path}.id`);
  stringValue(message.session_id, `${path}.session_id`);

  return {

    state: result.state === null ? null : decodeState(result.state, `${path}.state`),

    "error_type",
    "body",
    "diagnostic_id",

export function decodeComposerOperationStatus(value: unknown): ComposerOperationStatus {
  const envelope = exactRecord(
    value,
    "response",
    [
      "operation_id",
      "kind",
      "status",
      "cancel_requested",
      "poll_after_ms",
      "deadline_at",
      "deadline_remaining_ms",
    ],
    ["result", "error"],
  );
  const base = {
    operation_id: canonicalUuid(envelope.operation_id, "response.operation_id"),
    kind: decodeKind(envelope.kind, "response.kind"),
    cancel_requested: booleanValue(envelope.cancel_requested, "response.cancel_requested"),
    poll_after_ms: nonNegativeInteger(envelope.poll_after_ms, "response.poll_after_ms"),
    deadline_at: timestamp(envelope.deadline_at, "response.deadline_at"),
    deadline_remaining_ms: nonNegativeInteger(
      envelope.deadline_remaining_ms,
      "response.deadline_remaining_ms",
    ),
  };
  const result = optionalNullable(envelope, "result");
  const error = optionalNullable(envelope, "error");
  const status = decodeLifecycleStatus(envelope.status, "response.status");
  switch (status) {
    case "queued":
    case "running":
      if (result !== null) invalid("response.result", "a nonterminal operation carries no result");
      if (error !== null) invalid("response.error", "a nonterminal operation carries no error");
      return { ...base, status, result: null, error: null };
    case "completed":
      if (error !== null) invalid("response.error", "a completed operation carries no error");
      return { ...base, status, result: decodeResult(result, "response.result"), error: null };
    case "failed":
      if (result !== null) invalid("response.result", "a failed operation carries no result");
      return { ...base, status, result: null, error: decodeError(error, "response.error") };
  }
}

    default:
      return null;

}

}
```

```ts
 * response header, and a body without detail yields detail "" — what

export async function parseResponse<T>(
  response: Response,
  options: ParseResponseOptions = {},
): Promise<T> {
  if (!response.ok) {
    // A rejected credential can only invalidate the login that sent it.
    // Dynamic import avoids circular dependency at module load time
    // (authStore imports from client, client imports authStore for logout).
    if (response.status === 401 && options.logoutOnUnauthorized !== false) {
      const { useAuthStore } = await import("@/stores/authStore");
      if (responseOwnsCredential(response, useAuthStore.getState().token)) {
        await useAuthStore.getState().logout();
      }
    }

    // Parse the error envelope into one ApiError contract. Canonical backend
    // fields are `error_type`, `detail`, and optional `errors`; `kind` and
    // `message` remain accepted as compatibility aliases for older execution
    // responses.
    let body: unknown;
    try {
      body = await response.json();
    } catch {
      // Response body wasn't JSON -- use statusText as detail fallback
      body = undefined;
    }
```

```ts
/**
 * Per-tab custody of freeform composer operations (spec 2026-09-16 §2,
 * contract §Frontend).
 *
 * The SPA mints the operation id BEFORE the POST and keeps the id AND the
 * exact strict request body until it observes a terminal row, so an
 * ambiguous transport failure or a same-tab reload can poll by id and, only
 * when no row exists, resubmit the identical id/body. This DELIBERATELY
 * reverses guidedOperationRetry's fingerprint-only invariant for these two
 * kinds (guidedOperationRetry.test.ts:89 pins that invariant for the guided
 * kinds, which are unchanged): a fingerprint cannot be resubmitted, and
 * reload-resume is the point. The body is what the user typed in this tab;
 * it lives in sessionStorage (per tab, gone with the tab) and is removed at
 * the first observed terminal row, on logout (sessionStore.reset) and after
 * 24 h. There is NO orphan sweep on selectSession: a descriptor that
 * survives a reload is exactly what resumeComposerOperation must find.
 *
 * Other tabs never see this storage; a second tab learns about a running
 * operation from the server's 409 composer_operation_active (contract D8).
 */
import type {
  ComposerOperationKind,
  ComposerOperationRequestBody,
} from "@/types/composerOperations";

export const COMPOSER_OPERATION_CUSTODY_STORAGE_KEY = "elspeth_composer_operations_v1";
const STORAGE_SCHEMA = "composer-operations.v1";
const MAX_DESCRIPTOR_AGE_MS = 24 * 60 * 60 * 1000;
export const MAX_COMPOSER_OPERATION_CUSTODY_BYTES = 256 * 1024;
// crypto.randomUUID() output (version 4, RFC variant).
const OPERATION_UUID_PATTERN = /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/;
// sessions.id is String(128) (src/elspeth/web/sessions/models.py).
const MAX_SESSION_ID_LENGTH = 128;

export interface ComposerOperationDescriptor {
  sessionId: string;
  operationId: string;
  kind: ComposerOperationKind;
  body: ComposerOperationRequestBody;
  createdAt: number;
}

export type ComposerOperationCustodyRequest =
  | {
      sessionId: string;
      kind: "compose_message";
      content: string;
      stateId: string | undefined;
    }
  | { sessionId: string; kind: "compose_recompose" };

// The page's authority once loaded (null = not read from storage yet). A
// refused or partial storage write never loses custody for THIS page.
let memory: ComposerOperationDescriptor[] | null = null;

function storageOrNull(): Storage | null {
  try {
    return typeof window === "undefined" ? null : window.sessionStorage;
  } catch {
    return null;
  }
}

function isSessionId(value: unknown): value is string {
  return typeof value === "string" && value.length > 0 && value.length <= MAX_SESSION_ID_LENGTH;
}

function isBody(kind: ComposerOperationKind, value: unknown, operationId: string): boolean {
  if (typeof value !== "object" || value === null || Array.isArray(value)) return false;
  const body = value as Record<string, unknown>;
  const keys = Object.keys(body);
  if (body.operation_id !== operationId) return false;
  if (kind === "compose_recompose") return keys.length === 1;
  const allowed = new Set(["operation_id", "content", "state_id"]);
  if (!keys.every((key) => allowed.has(key))) return false;
  if (typeof body.content !== "string") return false;
  return (
    !Object.prototype.hasOwnProperty.call(body, "state_id") ||
    (typeof body.state_id === "string" && body.state_id.length > 0)
  );
}

function isDescriptor(value: unknown): value is ComposerOperationDescriptor {
  if (typeof value !== "object" || value === null || Array.isArray(value)) return false;
  const record = value as Record<string, unknown>;
  return (
    (record.kind === "compose_message" || record.kind === "compose_recompose") &&
    isSessionId(record.sessionId) &&
    typeof record.operationId === "string" &&
    OPERATION_UUID_PATTERN.test(record.operationId) &&
    typeof record.createdAt === "number" &&
    Number.isFinite(record.createdAt) &&
    record.createdAt >= 0 &&
    isBody(record.kind, record.body, record.operationId)
  );
}

function live(
  descriptors: readonly ComposerOperationDescriptor[],
  now = Date.now(),
): ComposerOperationDescriptor[] {
  return descriptors.filter(
    (descriptor) =>
      descriptor.createdAt <= now && now - descriptor.createdAt <= MAX_DESCRIPTOR_AGE_MS,
  );
}

function encoded(descriptors: readonly ComposerOperationDescriptor[]): string {
  return JSON.stringify({ schema: STORAGE_SCHEMA, descriptors });
}

function byteLength(value: string): number {
  return new TextEncoder().encode(value).byteLength;
}

function load(): ComposerOperationDescriptor[] {
  if (memory !== null) {
    memory = live(memory);
    return memory;
  }
  const storage = storageOrNull();
  let raw: string | null = null;
  if (storage !== null) {
    try {
      raw = storage.getItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      raw = null;
    }
  }
  if (raw === null) {
    memory = [];
    return memory;
  }
  try {
    if (byteLength(raw) > MAX_COMPOSER_OPERATION_CUSTODY_BYTES) {
      throw new Error("oversized composer operation custody envelope");
    }
    const parsed = JSON.parse(raw) as unknown;
    if (typeof parsed !== "object" || parsed === null) {
      throw new Error("invalid composer operation custody envelope");
    }
    const envelope = parsed as Record<string, unknown>;
    if (envelope.schema !== STORAGE_SCHEMA || !Array.isArray(envelope.descriptors)) {
      throw new Error("invalid composer operation custody envelope");
    }
    if (!envelope.descriptors.every(isDescriptor)) {
      throw new Error("invalid composer operation custody descriptor");
    }
    memory = live(envelope.descriptors);
  } catch {
    memory = [];
    try {
      storage?.removeItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      // Memory is authoritative for this page either way.
    }
  }
  return memory;
}

function persist(descriptors: ComposerOperationDescriptor[]): void {
  memory = descriptors;
  const storage = storageOrNull();
  if (storage === null) return;
  // The newest descriptors win the byte budget: evict the oldest from STORAGE
  // until the envelope fits. An evicted descriptor stays in this page's
  // memory; only a reload loses it, and the server's 409
  // composer_operation_active is the backstop for that (contract D8).
  const stored = [...descriptors].sort((left, right) => left.createdAt - right.createdAt);
  while (stored.length > 0 && byteLength(encoded(stored)) > MAX_COMPOSER_OPERATION_CUSTODY_BYTES) {
    stored.shift();
  }
  if (stored.length === 0) {
    // Tombstone and physical removal are independent clearance paths
    // (guidedOperationRetry.ts:161-183): attempt both.
    try {
      storage.setItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY, encoded([]));
    } catch {
      // removeItem below may still clear the stale envelope.
    }
    try {
      storage.removeItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY);
    } catch {
      // The tombstone above may already be the durable empty generation.
    }
    return;
  }
  try {
    storage.setItem(COMPOSER_OPERATION_CUSTODY_STORAGE_KEY, encoded(stored));
  } catch {
    // Quota refusal or disabled storage: memory stays authoritative for this
    // page; a reload then cannot resume (the 409 backstop above applies).
  }
}

/** Mint the operation id, freeze the exact body, persist both. Replaces any
 *  descriptor the session already had: one per session (contract §Frontend). */
export function acquireComposerOperationCustody(
  request: ComposerOperationCustodyRequest,
): ComposerOperationDescriptor {
  if (!isSessionId(request.sessionId)) {
    throw new Error("composer operation sessionId must be a non-empty string of at most 128 characters");
  }
  const operationId = crypto.randomUUID();
  let body: ComposerOperationRequestBody;
  if (request.kind === "compose_message") {
    body = request.stateId
      ? { operation_id: operationId, content: request.content, state_id: request.stateId }
      : { operation_id: operationId, content: request.content };
  } else {
    body = { operation_id: operationId };
  }
  const descriptor: ComposerOperationDescriptor = {
    sessionId: request.sessionId,
    operationId,
    kind: request.kind,
    body,
    createdAt: Date.now(),
  };
  persist([
    ...load().filter((existing) => existing.sessionId !== request.sessionId),
    descriptor,
  ]);
  return { ...descriptor };
}

export function findComposerOperationCustody(
  sessionId: string,
): ComposerOperationDescriptor | null {
  const descriptor = load().find((candidate) => candidate.sessionId === sessionId);
  return descriptor === undefined ? null : { ...descriptor };
}

/** Clear custody for exactly this operation; a newer descriptor for the
 *  same session (a later action) is left alone. */
export function clearComposerOperationCustody(sessionId: string, operationId: string): void {
  const descriptors = load();
  const kept = descriptors.filter(
    (descriptor) =>
      !(descriptor.sessionId === sessionId && descriptor.operationId === operationId),
  );
  if (kept.length !== descriptors.length) {
    persist(kept);
  }
}

export function clearAllComposerOperationCustody(): void {
  persist([]);
}
```

```ts
function envelopeForRejection(reason: unknown): ComposerOperationError {
  if (
    typeof reason === "object" &&
    reason !== null &&
    typeof (reason as { status?: unknown }).status === "number"
  ) {
    const { status, ...fields } = reason as { status: number } & Record<string, unknown>;
    return {
      http_status: status,
      failure_code: "http_error",
      error_type: typeof fields.error_type === "string" ? fields.error_type : null,
      body: { detail: fields },
      diagnostic_id: null,
    };
  }
  // An undefined turn result or a non-ApiError rejection: the worker's
  // generic envelope (contract §Error projection).
  return {
    http_status: 500,
    failure_code: "operation_failed",
    error_type: "operation_failed",
    body: {
      detail: {
        error_type: "operation_failed",
        detail: "The composer request failed. Reference compose-turn-double.",
        diagnostic_id: "compose-turn-double",
      },
    },
    diagnostic_id: "compose-turn-double",
  };
}

function statusFor(
  operationId: string,
  turn: TurnRecord,
  cancelRequested: boolean,
): ComposerOperationStatus {
  const base = {
    operation_id: operationId,
    kind: turn.kind,
    cancel_requested: cancelRequested,
    poll_after_ms: 0,
    deadline_at: DOUBLE_DEADLINE,
    deadline_remaining_ms: DOUBLE_REMAINING_MS,
  };
  switch (turn.outcome.status) {
    case "running":
      return { ...base, status: "running", result: null, error: null };
    case "completed":
      return { ...base, status: "completed", result: turn.outcome.result, error: null };
    case "failed":
      return { ...base, status: "failed", result: null, error: turn.outcome.error };

}
```

```ts
// composer_async_operations row exists; the turn runs in a server worker and
// GET /operations/{id} is the ONLY settlement authority. The progress and
// in-flight message pollers stay as advisory UX and stop when the operation

/**
 * Client deadline (spec §5; contract F-B3; Review Focus #1). The server
 * reports the time left on its DATABASE clock; this tab adds its grace and
 * measures the rest on its own monotonic clock. `deadline_at` is never
 * compared to Date.now(): a browser clock minutes off would cancel a healthy
 * turn at once or never.
 *
 * Tighten-only. After the server deadline passes, `deadline_remaining_ms` is
 * clamped at 0, so overwriting on every body would push the local deadline
 * out by one poll interval per poll, and it would never fire. Each arm is at
 * or after the true deadline plus grace on this tab's clock, because the
 * server computed the remaining time before the body arrived. So the earliest
 * arm is never early.
 */
function armComposerOperationDeadline(
  attachment: ComposerOperationAttachment,
  remainingMs: number,
): void {
  const armed = performance.now() + remainingMs + COMPOSE_CLIENT_GRACE_MS;
  attachment.localDeadline =
    attachment.localDeadline === null ? armed : Math.min(attachment.localDeadline, armed);
}

async function deliverComposerOperationCancel(
  attachment: ComposerOperationAttachment,
): Promise<void> {
  if (
    attachment.cancelReason === null ||
    attachment.cancelDelivered ||
    attachment.cancelInFlight
  ) {
    return;
  }
  attachment.cancelInFlight = true;
  try {
    const answer = await api.cancelComposerOperation(
      attachment.sessionId,
      attachment.operationId,
    );
    // Operation missing = no row yet (the POST has not committed): keep the
    // intent; the poll loop retries delivery and acknowledgement recovery
    // withdraws instead of resubmitting while a cancel is pending. Session
    // missing counts as delivered: there is nothing left to cancel, and the
    // poll loop takes the session-not-found path.
    attachment.cancelDelivered = !(
      isComposerOperationNotFound(answer) && answer.not_found === "operation_missing"
    );
  } catch {
    // Transient: the poll loop retries delivery on its next iteration.
  } finally {
    attachment.cancelInFlight = false;
  }
}

/**
 * Transport ambiguity on submit: the request may have committed, so the id
 * is probed before anything is resubmitted (spec §2). The 15 s per-call
 * AbortSignal.timeout rejects as a TimeoutError DOMException — ambiguity
 * here, never the Stop copy (Stop no longer aborts a fetch). A 5xx may come
 * from a proxy that forwarded the POST. A malformed 202 body means the
 * server DID accept.
 */
function isAmbiguousComposerSubmitFailure(err: unknown): boolean {
  if (err instanceof TypeError || err instanceof ComposerOperationDecodeError) return true;
  if (typeof err !== "object" || err === null) return false;
  const record = err as { name?: unknown; status?: unknown };
  if (
    record.name === "TimeoutError" ||
    record.name === "AbortError" ||
    record.name === "NetworkError"
  ) {
    return true;
  }
  return typeof record.status === "number" && (record.status === 0 || record.status >= 500);
}

/** A poll answer retrying cannot change: any 4xx except 408 and 429. That
 *  includes a 404 whose body is neither contract body; the client decodes
 *  the two contract 404s into ComposerOperationNotFound and throws only the
 *  unrecognised ones. A 401 has already logged out. */
function isDefinitiveComposerPollRefusal(err: unknown): err is ApiError {
  if (typeof err !== "object" || err === null) return false;
  const status = (err as { status?: unknown }).status;
  return (
    typeof status === "number" &&
    status >= 400 &&
    status < 500 &&
    status !== 408 &&
    status !== 429
  );
}

type ComposerOperationAcknowledgement =
  | { kind: "attached"; first: ComposerOperationStatus | null }
  | { kind: "active"; refusal: ComposerOperationActiveRefusal }
  | { kind: "rejected"; error: ApiError }
  | { kind: "unconfirmed" }
  | { kind: "withdrawn" }
  | { kind: "session_missing" }
  | { kind: "superseded" };

async function acknowledgeComposerOperation(
  attachment: ComposerOperationAttachment,
  mode: "submit" | "probe",
): Promise<ComposerOperationAcknowledgement> {
  const body = attachment.body;
  if (body === null) return { kind: "attached", first: null };
  let probeFirst = mode === "probe";
  for (let attempt = 0; attempt < COMPOSER_OPERATION_SUBMIT_ATTEMPTS; attempt += 1) {
    if (probeFirst) {
      let probe: ComposerOperationStatus | ComposerOperationNotFound;
      try {
        probe = await api.fetchComposerOperation(
          attachment.sessionId,
          attachment.operationId,
        );
      } catch {
        if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
        await sleep(composerOperationBackoffMs(attempt));
        continue;
      }
      if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
      if (!isComposerOperationNotFound(probe)) return { kind: "attached", first: probe };
      // The session is gone (Review Focus #2): nothing may be resubmitted
      // into it.
      if (probe.not_found === "session_missing") return { kind: "session_missing" };
      // Spec §2: an initial operation-missing 404 is not proof the POST
      // cannot still commit; the resubmit's primary-key replay is the arbiter.
      // A pending Stop withdraws instead — the user no longer wants this
      // request.
      if (attachment.cancelReason !== null) return { kind: "withdrawn" };
    }
    try {
      const accepted = await api.submitComposerOperation(
        attachment.sessionId,
        attachment.kind,
        body,
      );
      if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
      if (
        accepted.operation_id !== attachment.operationId ||
        accepted.kind !== attachment.kind
      ) {
        return { kind: "unconfirmed" };
      }
      return { kind: "attached", first: null };
    } catch (err) {
      if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
      if (isComposerOperationActiveRefusal(err)) return { kind: "active", refusal: err };
      if (!isAmbiguousComposerSubmitFailure(err)) {
        return { kind: "rejected", error: err as ApiError };
      }
      await sleep(composerOperationBackoffMs(attempt));
      if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
      probeFirst = true;
    }
  }
  return { kind: "unconfirmed" };
}

type TerminalComposerOperationStatus = Extract<
  ComposerOperationStatus,
  { status: "completed" | "failed" }
>;

type ComposerOperationPollOutcome =
  | { kind: "terminal"; status: TerminalComposerOperationStatus }
  | { kind: "missing" }
  | { kind: "session_missing" }
  | { kind: "unreadable" }
  | { kind: "refused"; error: ApiError }
  | { kind: "superseded" };

async function pollComposerOperationToTerminal(
  attachment: ComposerOperationAttachment,
  first: ComposerOperationStatus | null,
): Promise<ComposerOperationPollOutcome> {
  let answer = first;
  let failures = 0;
  let delayMs = 0;
  for (;;) {
    if (answer !== null) {
      if (answer.status === "completed" || answer.status === "failed") {
        // Custody ends at the first observed terminal row whether or not this
        // attachment is still current: a detached tab must never replay a
        // settled result on its next reattach (recent-changes §10 risk 6).
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        return composerOperationIsCurrent(attachment)
          ? { kind: "terminal", status: answer }
          : { kind: "superseded" };
      }
      armComposerOperationDeadline(attachment, answer.deadline_remaining_ms);
      delayMs = answer.poll_after_ms;
      answer = null;
    }
    // Client deadline (spec §5; contract F-B3): checked on every iteration
    // before the sleep, so a poll outage still fires the last arm. Then an
    // explicit cancel; polling continues to the terminal row, which
    // reconciles.
    if (
      attachment.cancelReason === null &&
      attachment.localDeadline !== null &&
      performance.now() >= attachment.localDeadline
    ) {
      requestComposerOperationCancel(attachment, "deadline");
    }
    if (attachment.cancelReason !== null) void deliverComposerOperationCancel(attachment);
    if (delayMs > 0) await sleep(delayMs);
    if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
    try {
      const polled = await api.fetchComposerOperation(
        attachment.sessionId,
        attachment.operationId,
      );
      if (isComposerOperationNotFound(polled)) {
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
        // A gone session stops the loop for good: no retry, no resubmit
        // (Review Focus #2). A missing row in a live session resyncs.
        return polled.not_found === "session_missing"
          ? { kind: "session_missing" }
          : { kind: "missing" };
      }
      failures = 0;
      answer = polled;
    } catch (err) {
      if (!composerOperationIsCurrent(attachment)) return { kind: "superseded" };
      if (err instanceof ComposerOperationDecodeError) {
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        return { kind: "unreadable" };
      }
      if (isDefinitiveComposerPollRefusal(err)) {
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        return { kind: "refused", error: err };
      }
      // Transient (network, 5xx, 408/429, the 15 s timeout): back off and
      // never declare the turn failed (spec §5).
      delayMs = composerOperationBackoffMs(failures);
      failures += 1;
    }
  }
}

function adoptActiveComposerOperation(
  attachment: ComposerOperationAttachment,
  refusal: ComposerOperationActiveRefusal,
): ComposerOperationAttachment {
  // Our body was never accepted. Drop the optimistic row (a Retry on a row
  // the server never saw would recompose ANOTHER message) or restore the
  // retried row, then wait on the operation that owns the session.
  useSessionStore.setState((s) => ({
    error: refusal.detail,
    messages:
      attachment.origin === "optimistic"
        ? s.messages.filter((m) => m.id !== attachment.targetMessageId)
        : attachment.origin === "retried"
          ? s.messages.map((m) =>
              m.id === attachment.targetMessageId
                ? { ...m, ...attachment.retriedRowPrior }
                : m,
            )
          : s.messages,
  }));
  return attachComposerOperation({
    sessionId: attachment.sessionId,
    operationId: refusal.active_operation.operation_id,
    kind: refusal.active_operation.kind,
    body: null,
    origin: "none",
    targetMessageId: null,
    retriedRowPrior: null,
    recoveryStartedCompositionVersion: attachment.recoveryStartedCompositionVersion,
    progressPollGeneration: attachment.progressPollGeneration,
    inflightPollGeneration: attachment.inflightPollGeneration,
  });
}

/** The row a failure marks: the optimistic/retried row on the live path;
 *  for a resumed or adopted operation, the latest user row with the custody
 *  content (send) or the latest user row (recompose, which by definition
 *  answers it), so the failed-row Retry is offered. */
function composerOperationFailureTargetId(
  attachment: ComposerOperationAttachment,
  messages: ChatMessage[],
): string | null {
  if (attachment.targetMessageId !== null) return attachment.targetMessageId;
  const body = attachment.body;
  const content = body !== null && "content" in body ? body.content : null;
  for (let index = messages.length - 1; index >= 0; index -= 1) {
    const candidate = messages[index];
    if (candidate.role !== "user") continue;
    if (content === null || candidate.content === content) return candidate.id;
  }
  return null;
}

async function applyComposerOperationSuccess(
  attachment: ComposerOperationAttachment,
  result: MessageWithStateResponse,
): Promise<void> {
  const sessionId = attachment.sessionId;
  // Canonical DB sync first, exactly as the synchronous route did: after this
  // await, messages hold every row the turn persisted and the optimistic
  // local-* row is gone once its canonical counterpart exists.
  await useSessionStore
    .getState()
    .loadInflightMessages(sessionId, attachment.inflightPollGeneration);
  if (!composerOperationIsCurrent(attachment)) return;
  const { message, state } = result;
  const proposals = result.proposals;
  useSessionStore.setState((s) => {
    // A resumed or adopted operation can settle after this tab already
    // loaded a NEWER head (reload, another tab): never roll it back.
    const acceptedState =
      attachment.origin === "none" &&
      state !== null &&
      s.compositionState !== null &&
      state.version < s.compositionState.version
        ? null
        : state;
    const previousVersion = s.compositionState?.version ?? null;
    const newVersion = acceptedState?.version ?? null;
    const versionChanged = newVersion !== null && newVersion !== previousVersion;
    // R4-H3: clear validation BEFORE updating compositionState when a new
    // state version arrives from the composer.
    if (versionChanged) {
      getExecutionStore().clearValidation();
    }
    const newState = acceptedState ?? s.compositionState;
    const nodeStillExists =
      !s.selectedNodeId || newState?.nodes.some((n) => n.id === s.selectedNodeId);
    const seen = new Set(s.messages.map((m) => m.id));
    const repaired =
      attachment.targetMessageId === null
        ? s.messages
        : s.messages.map((existing) =>
            existing.id === attachment.targetMessageId
              ? {
                  ...existing,
                  local_status: undefined,
                  local_error: undefined,
                  local_failure_code: undefined,
                }
              : existing,
          );
    const finalMessages = seen.has(message.id) ? repaired : repaired.concat(message);
    return {
      messages: finalMessages,
      compositionState: newState,
      // "Pipeline updated" vs "Response ready" (elspeth-bf9c296ee5).
      lastComposeChangedPipeline: versionChanged,
      compositionProposals: mergeCompositionProposals(s.compositionProposals, proposals),
      isComposing: false,
      ...(nodeStillExists ? {} : { selectedNodeId: null }),
    };

async function applyComposerOperationFailure(
  attachment: ComposerOperationAttachment,
  apiErr: ApiError,
  failureCode: ComposerOperationError["failure_code"] | null,
): Promise<void> {
  const cancelled = failureCode === "request_cancelled";
  const errorMessage = cancelled
    ? attachment.cancelReason === "deadline"
      ? COMPOSE_TIMEOUT_MESSAGE
      : COMPOSE_CANCELLED_MESSAGE
    : composeFailureMessage(attachment.kind, apiErr);
  // F-4b: on an audit-integrity refusal the user row IS committed (the
  // insert precedes every audit-guard raise site) — clear the pending bit
  // instead of failing it. Send only, as before.
  const auditIntegrityRefusal =
    !cancelled &&
    attachment.kind === "compose_message" &&
    apiErr.error_type === "audit_integrity_error";
  // S1: thread the closed failure code (e.g. policy_blocked) onto the row.
  const localFailureCode =
    !cancelled && typeof apiErr.failure_code === "string" ? apiErr.failure_code : undefined;
  const recoveryPatch =
    !cancelled && isComposerRecoveryError(apiErr)
      ? {
          recoveryError: apiErr,
          recoveryStartedCompositionVersion: attachment.recoveryStartedCompositionVersion,
        }
      : {};
  if (!composerOperationIsCurrent(attachment)) return;
  // Applied AFTER recoveryPatch so a salvaged draft rebaselines the
  // apply-confirmation gate onto the version the store now shows.
  const partialStatePatch = cancelled
    ? {}
    : convergencePartialStatePatch(apiErr, useSessionStore.getState().selectedNodeId);
  useSessionStore.setState((s) => {
    const targetId = composerOperationFailureTargetId(attachment, s.messages);
    return {
      isComposing: false,
      error: errorMessage,
      messages:
        targetId === null
          ? s.messages
          : s.messages.map((existing) =>
              existing.id === targetId
                ? auditIntegrityRefusal
                  ? {
                      ...existing,
                      local_status: undefined,
                      local_error: undefined,
                      local_failure_code: undefined,
                    }
                  : {
                      ...existing,
                      local_status: "failed",
                      local_error: errorMessage,
                      local_failure_code: localFailureCode,
                    }
                : existing,
            ),
      ...recoveryPatch,
      ...partialStatePatch,
    };
  });
  if (cancelled || failureCode === "worker_lost") {
    // The turn ran and stopped (Stop, deadline, another tab, or process
    // death): pull its durable partial results into view.
    await resyncAfterSettledComposeTurn(
      attachment.sessionId,
      attachment.progressPollGeneration,
      attachment.inflightPollGeneration,
      attachment.recoveryStartedCompositionVersion,
    );
  }
}

  errorMessage: string,

async function settleComposerOperation(
  attachment: ComposerOperationAttachment,
  outcome: ComposerOperationPollOutcome,
): Promise<void> {
  switch (outcome.kind) {
    case "superseded":
      return;
    case "terminal":
      if (outcome.status.status === "completed") {
        await applyComposerOperationSuccess(attachment, outcome.status.result);
        return;
      }
      await applyComposerOperationFailure(
        attachment,
        api.apiErrorFromBody(outcome.status.error.http_status, outcome.status.error.body),
        outcome.status.error.failure_code,
      );
      return;
    case "refused":
      await applyComposerOperationFailure(attachment, outcome.error, null);
      return;
    case "session_missing":
      // Today's session-not-found path (Review Focus #2). Custody was cleared
      // in the poll loop; the finally in runComposerOperation stops the
      // pollers.
      if (composerOperationIsCurrent(attachment)) deactivateMissingSession();
      return;
    case "missing":
    case "unreadable":
      applyLocalComposerOperationFailure(
        attachment,
        outcome.kind === "missing"
          ? COMPOSER_OPERATION_MISSING_MESSAGE
          : COMPOSER_OPERATION_UNREADABLE_MESSAGE,
      );
      await resyncAfterSettledComposeTurn(
        attachment.sessionId,
        attachment.progressPollGeneration,
        attachment.inflightPollGeneration,
        attachment.recoveryStartedCompositionVersion,
      );
      return;
  }
}

/** Submit (or probe), poll to the terminal row, apply the route's existing
 *  reducer. The pollers stop only here, after the operation settled. */
async function runComposerOperation(
  initial: ComposerOperationAttachment,
  mode: "submit" | "probe",
): Promise<void> {
  let attachment = initial;
  try {
    const acknowledgement = await acknowledgeComposerOperation(attachment, mode);
    let first: ComposerOperationStatus | null = null;
    switch (acknowledgement.kind) {
      case "superseded":
        return;
      case "rejected":
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        await applyComposerOperationFailure(attachment, acknowledgement.error, null);
        return;
      case "unconfirmed":
        // Custody is released: if the POST did commit, the next send answers
        // 409 composer_operation_active and this tab attaches (contract D8).
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        applyLocalComposerOperationFailure(attachment, COMPOSER_OPERATION_UNCONFIRMED_MESSAGE);
        return;
      case "withdrawn":
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        applyLocalComposerOperationFailure(attachment, COMPOSE_CANCELLED_MESSAGE);
        return;
      case "session_missing":
        // The probe found the session gone (reload into an archived session,
        // or an epoch reset): never resubmit into it (Review Focus #2).
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        if (composerOperationIsCurrent(attachment)) deactivateMissingSession();
        return;
      case "active":
        clearComposerOperationCustody(attachment.sessionId, attachment.operationId);
        attachment = adoptActiveComposerOperation(attachment, acknowledgement.refusal);
        break;
      case "attached":
        first = acknowledgement.first;
        break;
    }
    const outcome = await pollComposerOperationToTerminal(attachment, first);
    await settleComposerOperation(attachment, outcome);
  } finally {
    const store = useSessionStore.getState();
    store.stopInflightMessagesPolling(attachment.sessionId, attachment.inflightPollGeneration);
    store.stopComposerProgressPolling(attachment.sessionId, attachment.progressPollGeneration);
    // One-shot terminal pickup — only while this operation still owns the
    // poller; the generation goes THROUGH the read as well.
    if (attachment.progressPollGeneration === composerProgressPollGeneration) {
      await store.loadComposerProgress(attachment.sessionId, {
        ownerGeneration: attachment.progressPollGeneration,
      });
    }
    if (composerOperationAttachment === attachment) {
      detachComposerOperation();
    }
  }
}
```
