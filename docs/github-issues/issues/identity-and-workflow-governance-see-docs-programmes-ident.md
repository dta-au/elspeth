Tracking issue for the identity and workflow governance programme. The detail lives in `docs/programmes/identity-workflow-governance/`: `README.md` holds the scope, the documents of record and all sixteen steps.

## Scope

Pluggable SSO and the identity substrate; send-for-approval (blocking) and send-for-review (non-blocking); the shared library and personal lists; per-person token and storage quotas; compartment marking; the approver audit view; the mailbox; and the operator cutover.

This is product governance — approvals and quotas for the people using ELSPETH. It is not the project's internal code-signing machinery.
