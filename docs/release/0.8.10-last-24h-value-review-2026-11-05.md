Runtime restore passes its actual admitted source into message producers. `continuation_application_copy.py` copies the mutable application graph while retaining immutable recorder content and preserving the existing alias partition; `AdmittedTurnEvidence.copy_graph` checks the exposed graph before copying. `_restore_live` defers binding a new provider cost budget until final source proof, so a failed restore does not contaminate a reusable owner.

This is an architectural enhancement with a concrete benefit: less work on the same request, retaining current SQL/policy checks and independent mutable result-application state.
