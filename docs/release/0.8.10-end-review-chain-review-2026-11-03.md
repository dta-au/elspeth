## P2 — Cold action preview still requires the original live creator generation

The cold consequence API explicitly describes restoring a result after owner
loss, and its cold writer takes the current `running` from the restored runtime
([cold source](../../src/elspeth/web/composer/continuation_checkpoint_end_cold_consequence.py#L1),
[writer selection](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_review.py#L435)).
It then reaches the common action preview, which requires the original outer
effect's creator sequence and generation to equal the current running claim
([creator equality](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_action.py#L155)).

After a replacement claim, D and its outer effect still belong to the original
creator; the current claimant's generation differs. The shared predicate
therefore rejects the cold action preview before settlement even if the deep
H proof, current claim, original D, and pending-cohort checks all succeed.
This preserves data but leaves the paid H unconsumed on this path. Removing
the equality indiscriminately would weaken the warm writer: distinguish the
current fenced writer from the historical effect creator and re-prove each
under the appropriate contract, or explicitly limit the cold API to loss of
in-memory objects within the same claim. This finding is based on the exact
predicate, not a claim that a production recovery caller currently exists.
Native replacement-claim validation remains required.

## Conditional parity observation — empty state and a valid prior preflight

The cold clean path emits `AdvisorGatePassed` whenever `prior` exists and is
valid ([cold decision](../../src/elspeth/web/composer/continuation_checkpoint_end_cold_review.py#L210)).
The legacy warm decision additionally excludes structurally empty state
([warm decision](../../src/elspeth/web/composer/composition_completion.py#L3007)).
The cold no-effectful-recheck predicate does not itself exclude this combination.
For that input combination the decisions differ and `_with_advisor_gate_decision`
stores the difference in the result. This review did not establish that a
valid prior preflight on an unchanged empty state is reachable from current
production producers; it is therefore a conditional parity limitation, not a
confirmed production defect. Use the same predicate or prove exclusion in
the future native parity checks.

## Source dispositions

- **Original semantic D remains distinct from physical P/A/H.** The warm
  preparation checks ordinal zero against `owed.phase_source`, and ordinal one
  against `owed.retry_history.selected`, while locating semantic Review at
  `owed.phase_source` in both cases
  ([writer preparation](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_review.py#L197)).
  The action preview repeats that separation. The cold reader obtains the
  settled historical H and requires its original phase source to equal D;
  its raw H-event check compares the dispatched locator with
  `historical_h.original_selected`, the actual physical A, rather than D
  ([cold chain](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_review_cold.py#L161)).
  Thus ordinal one retains H0 → retry marker → P1/A1/H1 without relabeling the
  retry-ready marker as semantic dispatch.
- **Fresh pending cohort under the writer lock.** The writer acquires
  `service._session_write_lock`, checks current running and exact H, then calls
  `require_end_pending_cohort_on_connection` before preparing or writing the
  consequence ([locked sequence](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_review.py#L457)).
  That helper reads current pending interpretation rows on the same connection
  and compares their complete ordered projection with H's retained gate cohort.
  Earlier asynchronous gate observation alone is not the writer's freshness
  proof.
- **Narrow no-site cold branch.** The cold projector refuses interpretation
  sites, orphan events, introduced repair context, graph-rejected gates,
  effectful preflight requirements, proof override, and authoring repair. Clean
  projection delegates to the existing finalizer and blocked projection uses
  the existing blocked-result builder. Clean requires publication admission;
  flagged-final and malformed-second-final block require no admission and a
  qualified preflight/absent-preflight branch. It retains the original candidate
  only as withheld evidence. The empty-state caveat above prevents an
  unconditional parity claim. Pending-site full support remains outside this
  review's accepted slice.
- **Second physical attempt is one semantic pass.** Both pass constructors use
  `provider_attempts=ordinal+1`, `format_reprompt_sent=(ordinal==1)`, and
  `first_attempt_accepted=(ordinal==0)`. For ordinal one, schema validity comes
  from the deep-proved first retry marker, not the second verdict
  ([pass constructors](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_pass.py#L41)).
  The durable reader checks those retry-derived fields against historical H
  and its marker ([pass reproof](../../src/elspeth/web/sessions/continuation_checkpoint_end_complete_review_cold.py#L329)).
- **Review result remains separate from Stop/publication.** The writer prepares
  exact result/frontier/candidate bytes and unpaid terminal reserve before
  mutation; consumes the physical child and outer Review action atomically;
  settles quota, writes one pass and paid audit cohort, consumes H, then invokes
  the cold result reader before returning. This is source-level transactional
  structure, not demonstrated rollback or PostgreSQL evidence. The stored
  Review result does not itself establish assistant publication or operation
  completion.
