# Task 0 retention evaluator, revision 3

This bounded repair targets the two hanging architecture files on
`release/0.8.10-assembly`. It supersedes section 8 revision 2 at `6af0328e3`
and incorporates the [Mythos confirmation review](0.8.10-handover/u46/mythos-a2-confirm.md).
It does not resume another release unit.

The depth-first evaluator cuts a re-entered AST identity to `(None, False)`.
Its exact memo depends on the current path's intersection with a dependency
footprint. Different paths through the same cyclic graph can therefore need
different entries. The handover records one root exceeding 5.4 million body
evaluations. The fail-closed evaluation budget remains a permanent backstop.

## Values and proof obligations

A graph node is an AST value and its actual `read_target` flag. Ordinary
roots and children use `False`; only an AugAssign target root uses `True`.
Callable capture has a distinct graph identity. Each node has `(O, R, A)`:

- `O` is a set of possible origins, including the unknown origin `None`.
- `R` says a protected enum may be retained.
- `A` says the entire reachable dependency graph is acyclic.

For every old DFS execution reaching `k`, its origin belongs to `O(k)`, and
its true retained bit implies `R(k)`. On an A-true node, **both** values are
exact: `O(k) = {origin_DFS(k)}` and `R(k) = retained_DFS(k)`.

At an A-true Name, producer origins collapse to their common origin, or to
`None` when they disagree. At an A-false Name they remain a union, including
the `None` disagreement alternative when multiple producers permit distinct
origins. This also applies to non-SCC Names downstream of cyclic inputs:
the DFS uniqueness join can return None even when no producer returns None.
Each
cyclic SCC member starts at `({None}, False, False)`; iteration only adds
origins or changes the retained bit to true.

## Static dependencies

Discovery reads AST and fixed lexical maps, never tentative graph values. A
non-Load Name with `read_target=False` is a leaf. Other Names read their
exact lexical producers:

- assignment, with-item and iterator sources;
- the containing Match subject for a pattern binding;
- only the formal's own paired eager default;
- function defaults, plus a nested function's capture node;
- a nested ClassDef's generic children, rather than a function capture;
- imports use fixed tables without a graph dependency.

An Attribute reads its base. A Call reads its function, every positional
argument and every keyword value unconditionally. A capture node reads all
defaults and body Load Names whose actual binding scope lies outside that
callable. A Lambda additionally reads its body. The generic case reads every
`ast.iter_child_nodes` child. Short-circuit values never decide graph edges.

Iterative SCC traversal discovers reachable non-final nodes without Python
recursion. Components finalize in dependency order. A singleton without a
self-loop evaluates once; a cyclic component uses a deterministic worklist
until no member changes. Reversing the worklist must preserve values and
rows. The final cache belongs to one unit and proof pass, keyed by graph
identity and actual `read_target`. Finality is closed under successors.

## Transfer rules and suppressions

Existing origin maps apply elementwise, including Attribute projection,
module traversal and iteration-element conversion. Name joins preserve the
old producer retained bits and static-origin rules.

A formal's origin is an **override**, not a union. For each paired-default
origin `d`, use its static origin unless that is `None` or kind `unknown`;
then use `d`. Retention includes the static origin's protected-enum kind and
the default's retained bit. Without a paired default keep the static origin.

For each Call callee origin `c`, derive one `f(c)`. First derive any enum
constructor origin. Replace it with the Call's own static origin when
`c == static_origin(func)` and the **Call's own static origin is non-None**.
This equality includes `None == None`; the callee's static origin need not
be known. Otherwise use the constructor origin or `None`.

A suppression fires only when each input it actually reads is final,
A-true and a singleton proving the DFS's exact premise:

- `isinstance`/`issubclass` read only the callee, retaining their exact
  two-argument/no-keyword syntax requirement. Cyclic arguments do not
  invalidate their scalar-result suppression.
- Attribute scalar projection reads only the base.
- `str(enum_value)` reads both the callee and sole argument.
- The Call's static supplier-scalar early return reads the callee origin
  establishing its static-origin override.

Otherwise retention falls through to the applicable callee, argument and
mapped-origin OR terms. A suppression can fire inside an SCC when its read
inputs are final exact nodes outside that SCC; its predicate is constant
during iteration. Inputs within the SCC are A-false and cannot activate a
suppression. Transfers inside SCCs are therefore monotone. Collapse occurs
only outside cyclic closures.

## Denial consumers

`retained_expression` projects every possible direct origin through the old
selection rule, keeping the original static origin unchanged. An A-true root
uses its exact retained bit. An A-false root includes the non-retained branch
and includes the retained branch **only when R is true**. An R-false root
must not invent enum-compound and defeat class-check suppression.

Consumers evaluate combinations of projected origin sets. Exemptions apply
to complete combinations, never because one element or argument qualifies.
Coupled predicates such as `enum_arguments[0]` stay coupled. Repeated reads
of the same `(value, use, read_target)` choose the same origin within one
combination. Emit each distinct existing denial reason once at the site;
this preserves the old row even if another choice also makes an earlier
predicate deny.

Enumeration may be lazy: run the existing scalar predicate with selected
origins, split an unresolved alternative into deterministically ordered
choices, and repeat. Cache each projected factor locally to that consumer,
including a conservative failed-root projection, so a later factor cannot
re-run an abandoned SCC for every earlier-factor assignment. This local
projection cache never publishes a failed graph state. Branches that never
read an input need not enumerate that factor. Charge every attempt,
including partial attempts, and every graph rule evaluation against **one
aggregate consumer cap**, in addition to the independent root cap. A
consumer-cap exception bypasses the nested root handler and is caught only
at the consumer boundary. The trip emits its named failure row and
conservatively denies that consumer. This bounds products without
per-argument approximation or a roots-times-products multiplication.

The separate boolean `retained_callable_capture` root uses its capture
node's R, including defaults and actual outer captures.

## Budget, termination and evidence

The root count resets at each root; the aggregate count resets once per
consumer and is not reset by nested roots. Both counts include graph rule
evaluations, while the aggregate also includes combination attempts. Each
consumer therefore performs at most the cap plus its failing increment in
counted work. Publish cache entries only after the entire SCC
converges. On budget exception discard all unfinished component values;
completed successors may remain cached. The next root re-derives abandoned
components. Repeated failures are bounded by roots times the budget. Never
cache a failed root as a successful conservative graph value.

Origin maps preserve qualified names or draw from finite fixed tables;
constructed member origins use the existing protected-method vocabulary.
The universe is finite, values grow monotonically, and iteration converges
or trips the deterministic budget.

Acceptance requires handwritten probes for every edge class and review
correction, positive and negative controls, bounded fail-before/pass-after
evidence, reversed worklist equality, deep/large cyclic scaling, and budget
abandonment without partial SCC publication. Replace DFS memo storage pins
with exact values/rows on G-acyclic roots and row supersets on G-cyclic roots.
The bounded reference DFS is a differential instrument, never the active
proof. Classify corpus roots by graph cyclicity, block on every dropped
row, adjudicate each added row, and re-derive the budget from measured new
work. Both planted mutation controls stay red. The final canonical gate
includes both formerly hanging files.

## Corpus instrument contract

`scripts/fencing_retention_corpus.py` observes both real root interfaces and
executes a second pass through the unchanged scalar consumer with separately
bounded legacy DFS roots. Root R/O comparisons alone do not certify consumer
rows. The second pass records genuine legacy failures and marks a consumer
incomplete if a required old root caps; it never substitutes a conservative
graph value and calls that an old result. Fully comparable acyclic consumers
require exact row sets; cyclic consumers require old-row inclusion. Added
and removed rows retain the actual AST occurrence and source line for
individual adjudication.

The instrument refuses empty or duplicate source inventories. Digests bind
the exact `SourceUnit.source` text under the gate's UTF-8/universal-newline
policy, with live authority inventory/content checks before parsing, before
analysis and after both passes. Known gate, graph helper, inventory loader
and instrument paths are hashed before loading the gate, then rechecked
across that import and after analysis. Actual gate/helper paths and the
loader's code filename must match those frozen paths. The surrounding
immutable process receipt binds the already running instrument itself.
Every consumer must visit
the expected AST walk position; shared context/operator singleton objects
therefore do not overwrite earlier occurrences. Root records reject
duplicate keys and repeated-answer changes.

Mismatch is exit 1. Capped root or legacy-consumer evidence is exit 2 and
explicitly partial, even if all completed comparisons agree. Empty sources,
source/proof drift or incomplete consumer enumeration raise and cannot be
reported as a clean corpus. Controls exercise real measured fixtures,
parse/read and mid-analysis changes, empty authority, duplicate/missing
records, direct value mismatches, and a projector mutation which changes
actual consumer rows while leaving every root R/O comparison unchanged.
These controls must pass before corpus output is used as acceptance evidence.
