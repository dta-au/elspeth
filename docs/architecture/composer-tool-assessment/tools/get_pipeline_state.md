# `get_pipeline_state` assessment

Baseline: `3b28d537be98234da8135c418bf185a998c18b68` — 0.8.9. Reconnaissance and design only.

## 1. Purpose and exposure

Inspect the current authored graph, one component, or a recoverable authoring document for a full replacement. This is state-sensitive, noncacheable discovery. The result is diagnostic unless the caller explicitly asks for set_pipeline_arguments and that serializer succeeds.

## 2. Contracts and authority

Optional component string: omitted/full-state aliases select the document; source selects the named sources map; a node ID or output name selects that component; set_pipeline_arguments selects the flat authoring document. Ordinary state output and set_pipeline wire input are different contracts. The web mutation needs the flat document wrapped in `{"pipeline": ...}`; the private planner terminal `emit_pipeline_proposal` takes the same envelope ([src/elspeth/web/composer/pipeline_planner.py:1587](../../../../src/elspeth/web/composer/pipeline_planner.py#L1587)). Exact argument export can refuse with round_trip_unavailable. Credential checking runs over the whole state using accessible secret reference names, then storage paths are redacted ([src/elspeth/web/composer/tools/sessions.py:2463](../../../../src/elspeth/web/composer/tools/sessions.py#L2463), [src/elspeth/web/composer/tools/sessions.py:2469](../../../../src/elspeth/web/composer/tools/sessions.py#L2469), [src/elspeth/web/composer/tools/sessions.py:2515](../../../../src/elspeth/web/composer/tools/sessions.py#L2515)).

Three distinct projections of the same state reach the model, and they differ in which server-owned option keys they carry (demonstrated in-memory; see §7):

| Projection | Producer | `approved_prompt_artifact_hash` / `source_authoring` | Review rows |
|---|---|---|---|
| Diagnostic (`full`/alias, `source`, node, output) | `_serialize_source` / `_serialize_node` / `_serialize_output` emit `deep_thaw(options)` verbatim ([src/elspeth/web/composer/tools/_common.py:1771](../../../../src/elspeth/web/composer/tools/_common.py#L1771), [src/elspeth/web/composer/tools/_common.py:1804](../../../../src/elspeth/web/composer/tools/_common.py#L1804), [src/elspeth/web/composer/tools/_common.py:1865](../../../../src/elspeth/web/composer/tools/_common.py#L1865)) | kept | stored rows verbatim |

## 3. Source trace to the user

`_execute_get_pipeline_state` validates the selector with `GetPipelineStateArgumentsModel` (`extra="forbid"`; a supplied `null` is rejected by `_OmittableString`), reads reference names when secret context exists, rejects raw credential material, selects `_serialize_set_pipeline_arguments` or source/node/output/full serializers, and applies `redact_source_storage_path`. `PIPELINE_STATE_RESPONSE_CONTRACT` admits the selected response variant; the authoring variant is additionally re-validated with `SetPipelineArgumentsModel.model_validate(..., strict=True)` ([src/elspeth/web/composer/tools/sessions.py:2462](../../../../src/elspeth/web/composer/tools/sessions.py#L2462), [src/elspeth/web/composer/tools/sessions.py:2483](../../../../src/elspeth/web/composer/tools/sessions.py#L2483), [src/elspeth/web/composer/tools/state_responses.py:395](../../../../src/elspeth/web/composer/tools/state_responses.py#L395), [src/elspeth/web/composer/tools/state_responses.py:465](../../../../src/elspeth/web/composer/tools/state_responses.py#L465)).

The freeform exposure is `get_tool_definitions` → wire projection → `composer_loop_tool_definitions`; the planner selects an ordered discovery subset, so exposure can narrow by phase ([src/elspeth/web/composer/tools/_dispatch.py:311](../../../../src/elspeth/web/composer/tools/_dispatch.py#L311), [src/elspeth/web/composer/provider_gateway.py:391](../../../../src/elspeth/web/composer/provider_gateway.py#L391), [src/elspeth/web/composer/pipeline_planner.py:1647](../../../../src/elspeth/web/composer/pipeline_planner.py#L1647)). The persisted response projection keeps only the envelope (`success`, `validation`, `affected_nodes`, `version`) and collapses `data` to the unknown-key sentinel, because the declarative redaction policy declares no response keys ([src/elspeth/web/composer/redaction.py:3830](../../../../src/elspeth/web/composer/redaction.py#L3830), [src/elspeth/web/composer/redaction.py:4332](../../../../src/elspeth/web/composer/redaction.py#L4332)); see get_pipeline_state-N2. A completed lookup does not imply pipeline readiness.

The model can use the exact-document mode before set_pipeline; the UI receives an inspection event rather than an applied-state version. In approval mode a preceding set_pipeline returns `APPROVAL_REQUIRED` with "has not been applied", so a later read in the same turn shows the unapplied state, as it should ([src/elspeth/web/composer/tool_batch.py:2221](../../../../src/elspeth/web/composer/tool_batch.py#L2221)).

## 4. Branches, failures and recovery

Credential refusal happens before any component disclosure, and it covers the whole state. A clean node is refused if any other component carries credential-shaped material, and the fixed detail text does not name the location ([src/elspeth/contracts/credential_material.py:24](../../../../src/elspeth/contracts/credential_material.py#L24)). On freeform this branch is defence-in-depth: the same check runs before the provider call ([src/elspeth/web/composer/service.py:1178](../../../../src/elspeth/web/composer/service.py#L1178)). On MCP it is unreachable as a ToolResult because dispatch raises first. Exact reconstruction failure is explicit; it must not become a guessed document.

Selection order (corrected): `component == "set_pipeline_arguments"` (exact) → `component == "source"` (exact) → node id (exact) → output name (exact) → full-state alias (`strip().lower()`) → not found; an omitted component returns the full state ([src/elspeth/web/composer/tools/sessions.py:2483](../../../../src/elspeth/web/composer/tools/sessions.py#L2483), [:2493](../../../../src/elspeth/web/composer/tools/sessions.py#L2493), [:2497](../../../../src/elspeth/web/composer/tools/sessions.py#L2497), [:2501](../../../../src/elspeth/web/composer/tools/sessions.py#L2501), [:2504](../../../../src/elspeth/web/composer/tools/sessions.py#L2504), [:2507](../../../../src/elspeth/web/composer/tools/sessions.py#L2507)). Real ids therefore take precedence over aliases (pinned by [tests/unit/web/composer/test_tools.py:1473](../../../../tests/unit/web/composer/test_tools.py#L1473)), but the two reserved selectors take precedence over ids. Aliases are case- and whitespace-insensitive; `source`, `set_pipeline_arguments`, ids and output names are not (get_pipeline_state-N3).

Unknown components fail without state mutation and without an `error_code` (get_pipeline_state-N1). Source mode returns all named sources, not one compatibility source. Argument rejection occurs before the handler on public routes; on internal direct calls the handler's own `_validate_mutation_arguments` raises `ToolArgumentError`. Expected policy/semantic refusal is a failed result on the current state; controlled-code exceptions remain framework/plugin failures, with the executed prefix and audit evidence retained by the common loop. A `list_refs` failure in the secret service propagates as such an exception, because the handler calls it on every invocation ([src/elspeth/web/composer/tools/sessions.py:2463](../../../../src/elspeth/web/composer/tools/sessions.py#L2463)). Cancellation, timeout and final persistence failure belong to the request/operation owner, not a handler-local retry. None of these discovery handlers commits graph changes or needs a proposal approval step. Retrying a lookup can recover an argument or infrastructure problem but cannot repair the graph by itself.

Exact-export refusal reasons ([src/elspeth/web/composer/tools/_common.py:3981](../../../../src/elspeth/web/composer/tools/_common.py#L3981), [src/elspeth/web/composer/tools/_common.py:4027](../../../../src/elspeth/web/composer/tools/_common.py#L4027)): resolved review state not reconstructible; a named or multiple blob-backed source; a non-scalar or widened default `blob_ref`; and a default source with `source_authoring`, `mode: bind_source` or a path containing the substring `/blobs/` but no scalar `blob_ref` (get_pipeline_state-N4).

**Cache, idempotency, concurrency and retry:** `ToolKind.DISCOVERY`, `cacheable=False`. Each call serializes its supplied immutable state; accessible secret-reference names may be read from the scoped secret service. Repetition does not mutate graph/storage but is audited again and may observe a newer caller-supplied state. The serializer does not acquire a write lock or reread the session head atomically with references; operation/request ownership supplies that context. Exact export is not a compare-and-swap token. No handler retry occurs; on round_trip_unavailable the correct action is preserve/refuse or a supported narrow edit, not repeated guessing.

## 5. Defects, restrictions and hypotheses

No defect affecting graph integrity or disclosure was demonstrated. The findings below are result-shape, accounting, audit-visibility and consistency issues. Deliberate restriction: historical or structurally unsupported states may be inspectable but not losslessly reconstructable as current public set_pipeline arguments. Secret/storage redaction means diagnostic output is not automatically authoring authority. This should remain a preserve/refuse boundary, especially during 0.8.10-lite reinspection.

## 6. Ownership, remediation and dependencies

State-serialization owner owns exact round-trip availability; credential owner owns sensitive-value refusal; orchestrator owns requesting the appropriate variant. A first-class tool contract should declare the returned variant and its authority explicitly so consumers cannot mistake a display document for an approved replacement. Avoid adding generic coercion or a fallback serializer that invents missing fields.

**Implementation risk:** Medium for serializer/authority changes, particularly blob/review round trips. Preserve the diagnostic-versus-authoring distinction and explicit refusal.
