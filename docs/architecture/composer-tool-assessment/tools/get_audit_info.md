# `get_audit_info` assessment

Baseline: `3b28d537be98234da8135c418bf185a998c18b68` — 0.8.9. Reconnaissance and design only.

## 1. Purpose and exposure

Explain mandatory Landscape auditing and operator ownership of audit backend/export configuration. It returns product policy facts, not session or run records. It is cacheable, argument-free discovery.

## 2. Contracts and authority

The `data` payload is constant: enabled=true, composer_modifiable=false, summary and audit_export_summary ([src/elspeth/web/composer/tools/generation.py:2489](../../../../src/elspeth/web/composer/tools/generation.py#L2489)). It deliberately exposes no backend URL, database type, key environment name, run IDs or lineage anchors. The handler does not query Landscape or WebSettings: it discards its context and returns string literals ([src/elspeth/web/composer/tools/generation.py:2488](../../../../src/elspeth/web/composer/tools/generation.py#L2488)). The surrounding result envelope is not constant: `_discovery_result` attaches the current state, its `validate()` output and the state version ([src/elspeth/web/composer/tools/_common.py:1279](../../../../src/elspeth/web/composer/tools/_common.py#L1279)), and a cache hit rebuilds that envelope from the then-current state (pinned by [tests/unit/web/composer/test_service.py:4669](../../../../tests/unit/web/composer/test_service.py#L4669)). Configuration modification is intentionally outside this tool's authority.

The mandatory-audit claim is backed by `LandscapeSettings` rejecting `enabled=false` ([src/elspeth/core/config.py:1772](../../../../src/elspeth/core/config.py#L1772)); the composer export omits the `landscape` key so the URL comes from `WebSettings.get_landscape_url()` at execution time ([src/elspeth/web/composer/yaml_generator.py:469](../../../../src/elspeth/web/composer/yaml_generator.py#L469), [src/elspeth/web/config.py:1483](../../../../src/elspeth/web/config.py#L1483)), and YAML import deliberately drops `landscape` ([src/elspeth/web/composer/yaml_importer.py:84](../../../../src/elspeth/web/composer/yaml_importer.py#L84)). The redaction policy declares the tool sensitive-data-free and redacts unknown argument keys ([src/elspeth/web/composer/redaction.py:2762](../../../../src/elspeth/web/composer/redaction.py#L2762), [src/elspeth/web/composer/redaction.py:3823](../../../../src/elspeth/web/composer/redaction.py#L3823)).

## 4. Branches, failures and recovery

A valid call returns the same facts independently of session run history. There is no branch that returns audit rows or reconfigures logging. Invalid arguments are rejected at two gates: the public closed-schema gate before the handler (freeform/MCP/planner, `ARG_ERROR` routing) and the handler's own unconditional `EmptyToolArgumentsModel` check, which raises `ToolArgumentError` for any key (measured: `{"x": 1}` and an undecoded `{"_elspeth_no_arguments": true}` both raise `model_validation`). Expected policy/semantic refusal is a failed result on the current state; controlled-code exceptions remain framework/plugin failures, with the executed prefix and audit evidence retained by the common loop. A malformed producer payload fails response admission as `FrameworkBugError`, is recorded as `PLUGIN_CRASH` and is not cached ([tests/unit/web/composer/test_service.py:4736](../../../../tests/unit/web/composer/test_service.py#L4736)). Cancellation, timeout and final persistence failure belong to the request/operation owner, not a handler-local retry. None of these discovery handlers commits graph changes or needs a proposal approval step. Retrying a lookup can recover an argument or infrastructure problem but cannot repair the graph by itself.

**Cache, idempotency, concurrency and retry:** `ToolKind.DISCOVERY`, `cacheable=True`. The opt-in has effect only in the freeform loop, where constant policy facts are reused within one compose call. The planner route has no discovery cache; it de-duplicates by the `audit.info` information key and re-executes a repeated call. MCP has neither. No audit database is queried and no session write lock is needed. Every call, and every cache hit, still runs `state.validate()` to build the envelope. Repeated invocation is graph/store-idempotent but still records a tool audit decision. There is no handler retry or resource-probe retry, and a later primary-provider call does not transform these constants into observed session facts.
